====================================================================
  GUÍA DEFINITIVA DE CONFIGURACIÓN Y DESPLIEGUE EN SUPABASE (EDGE FUNCTION)
====================================================================

Sigue estos sencillos pasos en la web de Supabase para dejar funcionando el chatbot:

1. PASO 1: ENTRAR A SUPABASE WEB DASHBOARD
   - Entra a https://supabase.com/dashboard y abre tu proyecto (`eemqyrysdgasfjlitads`).

2. PASO 2: CREAR O REEMPLAZAR EL CÓDIGO EN EDGE FUNCTIONS
   - En el menú lateral izquierdo, haz clic en "Edge Functions".
   - Si no has creado la función, haz clic en "+ New Function" y nómbrala exactamente:
     gemini-chat
   - Abre el editor de código web que te muestra Supabase y COPIA Y PEGA todo el código que se encuentra en el archivo:
     supabase/functions/gemini-chat/index.ts
   - Guarda los cambios haciendo clic en "Save" / "Deploy".

3. PASO 3: CONFIGURAR LA VARIABLE / SECRET DE LA API KEY DE GEMINI
   - En el panel izquierdo de Supabase, ve a "Project Settings" -> "Edge Functions" -> "Secrets" (o dentro de Edge Functions en la pestaña "Secrets").
   - Agrega una nueva clave con el nombre EXACTO:
     GEMINI_API_KEY
   - En el valor de la clave, pega tu API Key de Google Gemini (no importa si empieza por AQ.A...).
   - Guarda el Secret.

4. PASO 4: CONFIGURACIÓN DE VERIFICACIÓN JWT
   - En "Project Settings" -> "Edge Functions", desactiva la opción "Verify JWT" para la función `gemini-chat` (o en la configuración de la función deshabilita Enforce JWT / Verify JWT).

5. URL DE LA EDGE FUNCTION QUE CONECTA CON EL CHATBOT:
   https://eemqyrysdgasfjlitads.supabase.co/functions/v1/gemini-chat
