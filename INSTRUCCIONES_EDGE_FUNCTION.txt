====================================================================
  GUÍA DE CONFIGURACIÓN PASO A PASO EN LA WEB DE SUPABASE (EDGE FUNCTIONS)
====================================================================

1. PASO 1: CREAR LA EDGE FUNCTION DESDE EL DASHBOARD WEB
   - Entra al Dashboard Web de Supabase (https://supabase.com/dashboard).
   - Selecciona tu proyecto (`eemqyrysdgasfjlitads`).
   - En el menú lateral izquierdo, haz clic en "Edge Functions".
   - Haz clic en el botón "+ Create a new Function" (o "New Function").
   - Nombra la función exactamente como: gemini-chat
   - Abre el editor de código web que se muestra en Supabase y COPIA Y PEGA todo el código que está en el archivo:
     supabase/functions/gemini-chat/index.ts
   - Haz clic en "Deploy" o "Save".

2. PASO 2: CONFIGURAR LA VARIABLE DE ENTORNO / SECRET DE LA API KEY
   - En el mismo panel de Supabase Web Dashboard, ve a "Edge Functions" -> "Secrets" (o "Project Settings" -> "Edge Functions" -> "Secrets").
   - Añade un nuevo Secret con el nombre EXACTO:
     GEMINI_API_KEY
   - En el valor, pega tu clave de API de Google Gemini (incluso si empieza por AQ.A...).
   - Guarda los cambios.

3. PASO 3: VERIFICACIÓN DE CONEXIÓN
   - La URL final que ejecutará tu chatbot será:
     https://eemqyrysdgasfjlitads.supabase.co/functions/v1/gemini-chat
   - El código en `docs/chatbot.js` ya está apuntando exactamente a esa dirección.
