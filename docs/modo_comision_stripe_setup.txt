MENUTECH COMMISSION MODE - STRIPE SETUP
=======================================

WHAT IT DOES (short version)
----------------------------
There are two modes:

1) Own Stripe (destination charge, restaurant pays Stripe fee)
   The customer pays only the order total. The platform pays Stripe's
   processing fee and recovers it through an application fee, so the
   restaurant receives the order total minus Stripe's fee. Menutech
   keeps 0% commission.

2) Menutech Commission (destination charge, restaurant pays Stripe fee)
   The customer pays only the order total. The application fee includes
   the commission plus Stripe's processing fee, so Menutech keeps the
   full commission and the restaurant receives the order total minus
   the commission minus Stripe's fee.
   Example: a $100 order with 10% commission
     -> Menutech keeps $10
     -> the restaurant receives $90 minus Stripe's fee.

THE COMMISSION TAB USES STRIPE CONNECT (YES, IT DOES)
-----------------------------------------------------
This is the part that confuses everyone, so read it once:

  Both tabs create the SAME kind of Stripe connected account.
  Both tabs show the SAME Stripe Account ID (acct_...).
  The only difference is who keeps what:

    Tab 1 "Own Stripe Account"
      commission_rate = 0
      The restaurant keeps 100%. Menutech charges nothing.

    Tab 2 "Menutech Commission"
      commission_rate = X%
      Menutech keeps X% via application_fee_amount.
      The restaurant receives the remaining (100 - X)%.

  Internally both are "destination charges": one payment, split in two.

So yes: in commission mode a Stripe Account ID IS generated, and the
commission tab now shows it with the same layout as tab 1
(Account ID / Details Submitted / Charges Enabled / Payouts Enabled).

WHY THE RESTAURANT STILL HAS TO REGISTER WITH STRIPE
----------------------------------------------------
This is a legal requirement, not a design choice. Stripe must verify who
receives the money (KYC/AML). There is no way to send money to a bank
account that Stripe has not verified.

What changes is who is the merchant of record:
  - Commission mode: YOU are. Charges, disputes and refunds are managed in
    YOUR account. The restaurant only receives a transfer.
  - Own Stripe mode: the restaurant is. They manage their own disputes.

WHERE THE RESTAURANT'S BANK ACCOUNT GOES
----------------------------------------
You never type it, and Menutech never sees the account number.
The restaurant enters it in the Stripe hosted form when you click
"Connect with Stripe" (in either tab).
Stripe stores it and makes the payouts. This is deliberate: handling raw
bank numbers yourself would put you in PCI/AML scope.

ONE-TIME STRIPE CONFIGURATION
-----------------------------
[ ] 1. Connect -> Settings -> Branding
       Name: Menutech / Color: #FF9533 / Icon: logomt.png (512x512)
       Optional, but the form then looks like yours.

[ ] 2. Connect -> Settings -> Payment methods
       Enable "Transfers". Required for destination charges.

[ ] 3. Connect -> Settings -> Payouts
       Leave Stripe's default schedule (daily/weekly). Payouts are automatic.
       Do NOT enable manual payouts, or the restaurant's money will sit
       waiting for you to release it by hand.

[ ] 4. Connected accounts must be Express.
       The code already creates them that way (dashboard: "express").

[ ] 5. Webhook events (existing webhook):
       - checkout.session.completed
       - account.updated
       account.updated keeps the connected status fresh by itself.

HOW TO USE IT IN THE PANEL (onlinePayment.html)
-----------------------------------------------
1. Open the "Menutech Commission" tab.
2. Click "Connect with Stripe" and let the restaurant fill the Stripe form.
   Same button, same look as tab 1. It only links the bank account; it does
   NOT change the payment mode.
3. Click "Check Status". The badge turns to "Connected & Enabled".
4. Type the commission % (for example 10). It saves automatically.
5. Click "Activate Commission Mode" and confirm.
6. Done. Every new order charges the commission automatically.

WHY THERE IS AN "ACTIVATE" BUTTON
---------------------------------
Saving the % and switching the mode are separate on purpose. In the past,
typing a % silently switched the restaurant into commission mode, which
charged a fee nobody had approved. Now the % is just a number until you
press Activate.

Activation is blocked while the account cannot receive funds. Without a
destination account the fee would be charged to the platform and the
restaurant would get nothing.

WHAT HAPPENS IF A RESTAURANT IS ALREADY ON OWN STRIPE AND YOU ACTIVATE
COMMISSION (OR THE OTHER WAY ROUND)
------------------------------------
Only one mode can be active at a time. They are stored in one row
(menutech_restaurant_payment_configs.payment_mode), so the last action wins.

  Own Stripe  -> Commission (10%)
    - A confirmation dialog warns you first.
    - commission_rate is set to 10 and payment_mode to menutech_commission.
    - From the NEXT order on, Menutech keeps 10%.
    - The Stripe account (acct_...) does not change. Same account, same
      history, same bank details.
    - Orders already paid are NOT re-charged. Commission is applied at
      checkout time and stored in that order's metadata.

  Commission -> Own Stripe
    - Confirmation dialog.
    - payment_mode becomes own_stripe and commission_rate is reset to 0.
    - From the NEXT order on the restaurant keeps 100%.

  Commission -> Revoke
    - payment_mode becomes none. Online payments stop until a mode is set.
    - The Stripe account stays connected.

So: no double charge, no retroactive fee, and no account is created twice.
The single thing to remember is that the change applies from the next order,
not to past ones.

RECOVERING AN ACCOUNT THAT WAS DISCONNECTED
-------------------------------------------
Disconnecting only removes the row in Menutech. The account is NOT deleted
in Stripe, so it can be linked again without losing its history.

Do it from the Supabase SQL Editor with docs/relink_stripe_account.sql
(paste the acct_... there). There is no button in the panel for this.

SEEING THE MONEY IN STRIPE
--------------------------
Stripe Dashboard -> Payments, filter by "Connected account".
You can also open the restaurant's Express dashboard from the panel with
"Open Express Dashboard".

IMPORTANT NOTES
---------------
- Commission 0% is not valid in this mode. Use "Own Stripe Account" instead.
- If onboarding is incomplete the badge stays "Pending Requirements" and
  commission cannot be activated. That is intentional.
- The customer pays only the order total; there is no surcharge.
- The restaurant bears Stripe's processing fee in both modes.
- Menutech commission is a fixed % of the order total; Stripe fees do not
  reduce it.
