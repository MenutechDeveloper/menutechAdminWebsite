====================================================================
EXPLICACIÓN: INTERFAZ DE RESERVACIONES VS INTERFAZ DE MENÚ DIGITAL
====================================================================

1. ¿POR QUÉ EL ENLACE A 'menu.html' MUESTRA EL MENÚ DE PLATILLOS?
   - El archivo 'docs/menu.html' en la plataforma está programado explícitamente para cargar el componente del Menú Digital e In-Store Orders (<menutech-platform-orders>).
   - Por esta razón, cualquier enlace hacia 'menu.html' siempre renderiza la lista de categorías, productos, carrito y pedidos online.

2. ¿CÓMO FUNCIONA LA INTERFAZ DE RESERVACIONES EN EL SISTEMA?
   - El sistema de reservaciones de Menutech utiliza un componente independiente llamado <menutech-reservations> (definido en 'docs/menutechUI.js').
   - Al insertar el widget o el código de reservaciones, se muestra la interfaz interactiva para reservar mesas (selección de número de personas, fecha, horarios según la configuración del restaurante, pre-pedido de platillos opcional y formulario de contacto del cliente).

3. CÓDIGO DEL WIDGET DE RESERVACIONES:
   - En 'docs/reservations.html', al presionar el botón "COPY CODE", se copia directamente al portapapeles el código custom element de reservaciones:

     <script src="https://menutech.io/menutechUI.js"></script>
     <menutech-reservations domain="tu-dominio.com"></menutech-reservations>

   - Al pegar este código en cualquier página web externa o dominio HTML, se muestra el botón y modal interactivo de reservaciones (no el menú).

4. MODO LINK DIRECTO PARA RESERVACIONES:
   - Para tener un link directo que abra únicamente la interfaz de reservaciones al hacer clic (sin pasar por el menú de platillos), se puede utilizar un archivo HTML dedicado a reservaciones (por ejemplo, 'reservation.html' o incluir el parámetro '?res=true' en un visor) que emplace directamente <menutech-reservations>.
